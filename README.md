# 🎮 Interactive Flask Mini Games Hub

A web-based interactive mini-games collection built using **Flask**, styled with custom playful CSS, animated Python-themed floating background words, and smooth cursor sparkles.

## 🕹️ Included Games
1. **Guess the Number** (1 - 100)
2. **Roll Two Dice** 🎲
3. **Coin Flip** 🪙 (with live stats tracking)
4. **Rock Paper Scissors** ✂️ (against computer opponent)
5. **Guess the Word** 🔤 (Hangman-style with hints and lives tracking)

## ✨ Features
* **Flask Server-Side Sessions**: Keeps track of game states, scores, and active turns.
* **Custom Interactive UI**: Features an off-white/pastel peach theme with light red container boxes, orange accents, and dynamic win/loss emojis.
* **Animated Background**: Floating Python-related terminology (`.py`, `flask`, `OOP`, `pandas`, etc.) that reacts to cursor hover.
* **Custom Cursor Trail**: Smooth pastel blue sparkling cursor effect.
